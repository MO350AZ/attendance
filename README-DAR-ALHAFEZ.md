# دار الحافظ — تحديث المشروع

هذا Pack لتحديث الريبو الحالي، وليس مشروعًا جديدًا.

## الملفات التي تُستبدل
- `index.html`
- `Code.gs`
- `manifest.json`
- `sw.js`
- `package.json`
- `capacitor.config.json`
- `tools/prepare_native.py`
- ملفات `icon-*.png` و `apple-touch-icon*.png`
- `.github/workflows/build-android.yml`
- `.github/workflows/build-ios.yml`

## ملفات جديدة
- `assets/icon.png`

## التغييرات
- اسم التطبيق: **دار الحافظ**.
- نفس Capacitor App ID القديم للحفاظ على تحديث التطبيق المثبت بدل إنشاء تطبيق ثانٍ.
- حقل المجموعة أصبح بحثًا/اختيارًا من المجموعات الموجودة أو كتابة مجموعة جديدة.
- المجموعات تُعرض أبجديًا.
- بيانات الطالب: الاسم، السن، المجموعة، رقم التليفون، رقم ولي الأمر.
- زر `💰 دفع` بجوار كل طالب.
- صفحة `💰 المدفوعات` لتسجيل المبلغ والتاريخ والفترة والملاحظات.
- المدفوعات تُحفظ محليًا وتتم مزامنتها إلى Google Sheets في ورقة `المدفوعات`.
- ورقة `الطلاب` أصبحت تحتوي على السن ورقم ولي الأمر.
- شعار دار الحافظ هو مصدر أيقونات PWA وAndroid وiOS.
- Android workflow مضبوط على Java 21.
- iOS workflow يبني IPA غير موقع ويضعه أيضًا كـRelease.
